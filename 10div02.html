10단 분해 나눗셈이란? · What is Base-10 Decomposition Division?

      
나누는 수(Divisor)를 가장 가까운 10의 배수(base)로 올림/내림하여 나누기 쉽게 만든 뒤, 그 차이(diff)만큼 보정을 더해 정확한 몫을 구하는 방법입니다.

      
곱셈구구를 모르더라도 10의 배수로만 나눌 수 있으면 임의의 나눗셈을 단계적으로 풀 수 있습니다.

    

    

      
알고리즘 단계 · Algorithm Steps

      

        
1

        
base 설정 · Set base: 나누는 수(Divisor)를 반올림하여 가장 가까운 10의 배수를 구합니다.
base = round(dv / 10) × 10

      

      

        
2

        
예비몫(q) 계산 · Preliminary Quotient: 현재 나머지를 base로 나눈 임시 몫을 구합니다. 이것은 아직 최종 몫이 아닙니다.
q = floor(rem / base)

      

      

        
3

        
보정(corr) 계산 · Correction: base와 실제 나누는 수의 차이(diff = base - dv)에 예비몫 q를 곱해 보정값을 구합니다.
corr = diff × q

      

      

        
4

        
새 나머지(fr) 계산 및 조정 · New Remainder: 빼기 후 보정을 더합니다. fr이 음수가 되면 dv를 더해 양수로 만들고, 그 횟수(borrow)만큼 예비몫에서 뺍니다.
fr = (rem - base×q) + corr
실제기여몫(aQ) = q - borrow

      

      

        
5

        
반복 · Repeat: fr ≥ dv이면 2번으로 돌아가 반복합니다. fr < dv가 되면 최종 나머지입니다.

      

    

    

      
예시 · Example: 87 ÷ 28

      
base = 30 (28을 반올림 · round up)
diff = 30 - 28 = +2

step 1: q = floor(87/30) = 2
  87 - 30×2 = 27
  +2×2 = +4 (보정 · correction)
  fr = 27 + 4 = 31  → 아직 ≥ 28

step 2: q = floor(31/30) = 1
  31 - 30×1 = 1
  +2×1 = +2 (보정 · correction)
  fr = 1 + 2 = 3  → 3 < 28 ✓

최종 몫 · Quotient = 2 + 1 = 3,  나머지 · Remainder = 3

    

    

      
왜 정확한가? · Why is it accurate?

      
각 단계에서 base로 나눈 오류를 diff×q로 정확히 상쇄합니다. 수식으로 보면:

      
rem = base×q + mid
     = (dv + diff)×q + mid
     = dv×q + diff×q + mid
→ fr = mid + diff×q = rem - dv×q

      
즉 fr은 rem을 dv로 q번 나눈 나머지와 수학적으로 동일합니다.
i.e. fr is mathematically identical to rem mod dv×q.
