에카뉴네나 푸르베나
Ekanyunena Purvena

एकन्यूनेन पूर्वेण  •  "이전 것보다 하나 적게"  •  "One less than the previous"

에카뉴네나 푸르베나는 9, 99, 999, 9999… 와의 곱셈을
단 2단계로 암산하는 베다 수학의 마법 같은 기법입니다.

핵심: 임의의 수 N을 9…9(k자리)와 곱할 때,
N × 9…9 = N × (10k − 1) = N × 10k − N
이 계산이 항상 LHS = N−1 과 RHS = 9…9 − (N−1) 로 깔끔하게 분리됩니다.

"Ekaṁ nyūnam pūrvena" means each digit is one less than before.
🔢 2단계 계산법 2-Step Method
A 왼쪽(LHS) = N − 1 Left side (LHS) = N minus 1
B 오른쪽(RHS) = 9…9 − LHS (항상 k자리 보장) Right side (RHS) = 9…9 minus LHS (always k digits)
★ 답 = LHS 와 RHS 를 이어 붙인 수 Answer = LHS concatenated with RHS
✏️ 예시 모음 Examples
예시 1) 24 × 99 Example 1) 24 × 99 LHS = 24−1 = 23  │  RHS = 99−23 = 76  →  2376

예시 2) 356 × 999 Example 2) 356 × 999 LHS = 356−1 = 355  │  RHS = 999−355 = 644  →  355644

예시 3) 878 × 9999 (자릿수 패딩: 878 → 0878) Example 3) 878 × 9999 (pad: 878 → 0878) LHS = 878−1 = 877  │  RHS = 9999−877 = 9122  →  8779122

💡 수학적 증명 (Mathematical proof)
N × 9…9 = N × (10k−1) = N·10k − N
앞부분 → N·10k 에서 N을 뺄 때 앞자리: N−1
뒷부분 → 10k−N = 9…9−(N−1)
