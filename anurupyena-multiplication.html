아누루파나 곱셈
Anurupyena Multiplication

अनुरूप्येण • "기준수에 맞게" • "In Proportion to the Base"

📐 핵심 원리 Core Principle
아누루파나(अनुरूप्येण)는 베다 수학(Vedic Mathematics)의 곱셈법으로,
두 수를 기준수(Base)에서의 차이(편차)로 분해하여 계산합니다.

기준수는 10의 거듭제곱(10, 100, 1000…) 또는
그것의 배수·분수(50, 200, 25, 500…)도 사용 가능합니다.

"अनुरूप्येण" — 비례하는 방식으로
핵심: (A×B) = (A+d₂)×Base + d₁×d₂
여기서 d₁=A−Base, d₂=B−Base
🔢 계산 순서 How It Works
1 기준수 선택 Choose Base
두 수에 가장 가까운 기준수를 선택합니다 (10, 50, 100, 200…)
2 편차 계산 Find Deviations
d₁ = A − Base, d₂ = B − Base (음수도 가능)
3 왼쪽(LHS) 계산 Calculate LHS
(A + d₂) = (B + d₁) — 두 계산은 항상 같은 결과
4 기준수 조정 Adjust for Base
기준수가 n×10ᵏ이면 LHS에 n을 곱하거나 10ᵏ으로 나눔
5 오른쪽(RHS) 계산 Calculate RHS
d₁ × d₂ = RHS. 기준수에 따라 자릿수 맞추기
6 합산 Combine
최종 결과 = LHS 부분 + RHS 부분 (올림 처리 주의)
✏️ 예시1: 46 × 46 (기준수 50 = 100÷2)
편차: 46−50 = −4 (둘 다)
LHS: (46+(−4)) = 42 → 기준 100÷2이므로 42÷2 = 21
RHS: (−4)×(−4) = 16 (2자리)
결과: 21 | 16 = 2116

✏️ 예시2: 57 × 57 (기준수 50 = 5×10)
편차: 57−50 = +7 (둘 다)
LHS: (57+7) = 64 → 기준 5×10이므로 64×5 = 320
RHS: 7×7 = 49 → 1자리(기준 10기준) 9남기고 4 올림
합산: 320 + 4 = 324, 뒤에 9 → 3249
